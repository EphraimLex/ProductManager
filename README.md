
# Product Management System

A C# console application for managing products.

## Features

- Add Product
- View Products
- Search Product
- Delete products
- Display product statistics
- Save products to a file when exiting

## Running the Application

1. Open the solution in Visual Studio.
2. Run the application.
3. Select an option from the menu.
4. Choose Exit to save the products and close the application.
